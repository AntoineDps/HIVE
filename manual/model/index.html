    Model¶

    Defines the body, the type and the force terms of a 1-DOF (heave) model. Consumed by run_validate and run_identify.

    Model files model.json live in source/models/<name>/.

    JSON config¶

    This is an example of model.json for a linear WEC (linear restoring, radiation state space, Froude-Krylov and diffraction convolution) with the PTO gains of the CFD case.

    {
  "name": "lin",
  "type": "physics",
  "description": "Linear",
  "body": {
    "hydro_sphere_pkl": "r5_m40",
    "rho": 1025,
    "g": 9.81
  },
  "force_terms": {
    "restoring": "linear",
    "radiation": "state_space",
    "fk": "linear_conv",
    "diffraction": "linear_conv",
    "pressure_field": null,
    "drag": null,
    "pto": {"stiffness": "cfd", "damping": "cfd"}
  }
}
    Field Type Required Description
    name string Yes Model name, normally the folder name containing model.json (not checked)
    type string Yes Model type. Only "physics" for now (data-based types will be added)
    description string No Free text
    body dict Yes hydro_sphere_pkl: name of the HydroSphere pickle in source/models/bem/<name>/ (BEM data, mass, radius, stiffness, water depth, panel mesh). rho, g: physical constants
    force_terms dict Yes Composable force model — see force_terms
    identified dict With drag: "viscous" Parameters written by run_identify (c_v, method, metric, …)

    The equation of motion is \((m + m_\infty)\,\ddot{x} = \sum F\), with \(m\) the body mass and \(m_\infty\) the infinite-frequency added mass (only with a radiation state_space term).

    force_terms¶

    Seven categories, all keys required, each holding at most one term: null means no term. A missing or unknown key is an error.

    Key Physics
    restoring Static (hydrostatic) pressure, including gravity
    radiation Radiation damping and added mass
    fk Froude-Krylov: dynamic pressure of the incident wave
    diffraction Scattered wave (linear)
    pressure_field Static + dynamic incident pressure in one panel integration (full nonlinear Froude-Krylov)
    drag Viscous drag
    pto Power take-off

    A term is written as a string, or as a dict {"type": ..., <parameters>} when it takes parameters. Any category can also be prescribed from the CFD. The full linear excitation is fk linear_conv + diffraction linear_conv.

    Conventions¶

    • Wave components \((A, \omega, k, \varphi)\), waves along +x, x = 0 at the buoy centre (reference wave gauge position): \(\eta(x, t) = \sum A \cos(\omega t - k x + \varphi)\). They come from the reconstructed wave elevation of the handled CFD case (_wave_recon.csv) or directly from the generated synthetic wave.
    • Water depth \(h\) is the BEM depth of the HydroSphere. \(k\) follows the dispersion relation \(\omega^2 = g k \tanh(k h)\) (\(k = \omega^2 / g\) in deep water).
    • Wetted surface is always determined using the true wave: the measured η(t) for flat terms, the recomposed wave with all components for _x terms.
    • Dynamic pressure is determined using the n_wave_components largest components of the wave ("all" for every component).
    • Wheeler stretching in every dynamic pressure: the depth profile is evaluated at the stretched coordinate \(z_s = h (z - \eta) / (h + \eta)\), \(\cosh(k (z_s + h)) / \cosh(k h)\) (\(e^{k (z - \eta)}\) in deep water). The dynamic pressure equals \(\rho g \eta\) at the surface and never grows above it.

    restoring¶

    Static pressure, gravity included.

    Option Free surface over the body Pressure Method Interpolation key Column
    "linear" — (mean surface) linearised: F = −K·x analytic — fhs_lin
    "nonlinear" η = 0 (still water) F = ρg·V_sub(x) − mg analytic (spherical cap) — fhs_nl
    "nonlinear_eta" flat η(t), measured F = ρg·V_sub(x, η) − mg, corresponds to p(z=η)=0 analytic restoring fhs_nl_eta
    "nonlinear_eta_z0" flat η(t), measured F = ρg·(V_sub − η·A_WP) − mg, from divergence theorem with p(z=0)=0 (Giorgi) analytic restoring fhs_nl_eta_z0
    "nonlinear_eta_x" η(x, t), recomposed p = ρg·(η(x_c, t) − z), corresponds to p(z=η)=0 panels — fhs_nl_eta_x
    "nonlinear_eta_z0_x" η(x, t), recomposed p = −ρg·z, corresponds to p(z=0)=0 panels — fhs_nl_eta_z0_x

    V_sub: submerged volume below the free surface. A_WP: waterplane area at the free-surface height. K = ρg·πr².

    radiation¶

    Option Formula Method Columns
    "state_space" F = −(Cr·z + Dr·ẋ), matrices from HydroSphere, added mass ma_inf folded into the left-hand side (m + ma_inf)·ẍ state space, radiation states z integrated with the body fr_damp (damping/memory part), fr_lin = fr_damp − ma_inf·ẍ (total, output only)

    fk¶

    Froude-Krylov: dynamic incident-wave pressure only. The static part is the restoring term.

    Option Free surface (mask + Wheeler) Dynamic pressure Method Parameters Interpolation key Column
    "linear_conv" — (mean surface, linear BEM) linear FK force: IRF ∗ η convolution, FK IRF from HydroSphere — excitation f_fk_lin
    "nonlinear" flat η(t), measured ρg·Σ A·f_k(z)·cos(ωt + φ) panels n_wave_components excitation f_fk_nl
    "nonlinear_x" η(x, t), recomposed ρg·Σ A·f_k(z)·cos(ωt − kx + φ) panels n_wave_components — f_fk_nl_x

    f_k(z): depth profile with Wheeler stretching (see Conventions). Example: "fk": {"type": "nonlinear_x", "n_wave_components": 30}.

    diffraction¶

    Option Formula Method Interpolation key Column
    "linear_conv" linear diffraction force: IRF ∗ η convolution, diffraction IRF from HydroSphere excitation fd_lin

    The nonlinear FK terms (fk nonlinear*, pressure_field) contain no diffraction: add "diffraction": "linear_conv" for the scattered wave.

    pressure_field¶

    Full incident pressure (static (p(z=0)=0) + dynamic) integrated in one panel pass, as in Giorgi's NLFK. The static and dynamic parts are still saved as two separate columns. The static column includes gravity, so no restoring term is needed with it.

    Option Free surface Pressure Method Parameters Interpolation key Columns
    "airy" flat η(t), measured −ρg·z + ρg·Σ A·f_k(z)·cos(ωt + φ) panels n_wave_components excitation fhs_nl_eta_z0 + f_fk_nl
    "airy_x" η(x, t), recomposed −ρg·z + ρg·Σ A·f_k(z)·cos(ωt − kx + φ) panels n_wave_components — fhs_nl_eta_z0_x + f_fk_nl_x

    airy_x gives exactly nonlinear_eta_z0_x + fk nonlinear_x, in one loop instead of two. airy differs from nonlinear_eta_z0 + fk nonlinear only by the panel error of the static part (analytic in nonlinear_eta_z0).

    n_wave_components: number of largest-amplitude wave components used for the dynamic pressure (positive integer or "all"). Lever on computation time.

    drag¶

    Option Formula Requires Column
    "viscous" F = −c_v·|ẋ|·ẋ (Morison-type) identified.c_v (from run_identify, scheme viscous_drag) f_visc

    pto¶

    Option Formula Columns
    {"stiffness": k, "damping": b} F = −k·x − b·ẋ, with numbers [N/m], [N·s/m] fs_pto, fd_pto, fpto
    {"stiffness": "cfd", "damping": "cfd"} same, with the gains of the CFD case (one or both keys) fs_pto, fd_pto, fpto
    {"type": "cfd", "force": <column>} PTO force prescribed from the CFD cfd_<column>, fpto
    null no PTO —

    "cfd" gains need a CFD case with a body: an error for synthetic waves and wave-only cases (empty basin). Synthetic models use numeric gains; their values appear in the synthetic CSV names (_d<damping>_k<stiffness>). In run_identify pi_gain, the optimised gains replace the model's PTO.

    CFD-prescribed forces¶

    Any category can be replaced by a force column of the CFD case, read as a time series: {"type": "cfd", "force": <column>}, e.g. "restoring": {"type": "cfd", "force": "ftot"}. The column is saved as cfd_<column> and feeds the role of its category. pressure_field takes {"type": "cfd", "static_force": ..., "dynamic_force": ...} (one or both). A prescribed radiation has no states (left-hand side mass m). Needs a CFD case with that column (error for synthetic waves). Interpolation key cfd.

    Role columns¶

    Every model also writes generic role columns, with the same name in every model (zeros if the category is absent), so models and CFD can be compared by name:

    Column Definition
    F_static static force (incl. −m·g): restoring, static part of pressure_field
    F_exc excitation: fk + diffraction, dynamic part of pressure_field
    F_rad total radiation (= fr_lin)
    F_drag viscous drag
    F_hyd total fluid force = F_static + m·g (if static present) + F_exc + F_rad + F_drag, comparable to the CFD fhyd_cfd
    fpto total PTO force

    Notes¶

    Time margins — t_warmup and t_causal are derived automatically from the model and BEM data and are not JSON inputs. Radiation state_space: t_warmup = 30 s. fk or diffraction linear_conv: t_warmup = t_irf end, t_causal = |t_irf start|. Panel terms need no margin. The largest values across the models of a run are applied to every simulation.
