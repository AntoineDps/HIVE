    run_handle_data¶

    Processes raw CFD time series into a standardised format ready for validation and identification. Wave-only datasets (empty wave basin, no body) can be processed too.

    Run¶

    first run¶

    python -m script.run_handle_data --case <name>.json

    Config files .json live in inputs/handle_case/. The filename stem becomes the output folder name under data/handled/.

    rerun options¶

    When the output folder already exists, the script prompts:

    [1] erase and redo all     — reprocess + replot from scratch
[2] stop, do nothing
[3] load saved figures     — reopen existing .pkl plots interactively
[4] remake figures only    — reuse processed CSVs, regenerate plots

    Option [4] is useful when tuning plot parameters without reprocessing data.

    what it does¶

    1. Reads each case folder from data/cfd/
    2. Instantiates a DataHandle object per case
    3. Calls processData() — computes the wave parameters (spectrum, \(H_s\), \(T_e\), energy flux, depth type, wave length) and, for a case with a body, the PTO force and absorbed power, the hydrostatic forces, the linear excitation force (fe_lin and its Froude-Krylov / diffraction parts) and the radiation force
    4. Optionally resamples to a target dt
    5. Decomposes the measured wave elevation into components \((A, \omega, k, \varphi)\) on the final time grid (energy band wave_energy_fraction), and saves the recomposed elevation eta_rec
    6. For a case with a body: computes the panel forces from the CFD motion and the recomposed wave (fhs_nl_eta_x, fhs_nl_eta_z0_x, f_fk_nl_x), with the same force classes as the models
    7. Saves processed data, wave parameters and wave components to data/handled/<name>/data/
    8. Generates and saves plots to data/handled/<name>/plots/

    Input JSON config¶

    {
  "wave_type": "irr",
  "cut_time": [30, 0],
  "duration": null,
  "hydro_sphere_pkl": "r5_m40",
  "dt": 0.05,
  "water_depth": 60,
  "wave_energy_fraction": 0.999,
  "n_wave_components": 100,
  "cases": [
    {
      "T": 6.5,
      "H": 2.0,
      "damping": 120000,
      "stiffness": -430000,
      "tag": "example",
      "plot": true
    }
  ],
  "plot_options": {
    "sea_state": true,
    "power": true,
    "dynamics": true,
    "hydro": true,
    "3d": true,
    "variable": ["fe_lin", "x"]
  }
}

    All fields are required.

    Field Type Description
    wave_type "irr" | "reg" Wave type used in the CFD simulation
    cut_time [float, float] Seconds to discard from [start, end] of the raw signal. Use 0 to keep to the edge
    duration float | null Maximum duration (s) to retain after the start cut. null keeps all remaining data
    hydro_sphere_pkl string Name of the BEM pickle source/models/bem/<name>/<name>.pkl, e.g. "r5_m40"
    dt float | null Target resampling timestep (s). null keeps the original CFD timestep
    water_depth float | "deep" Water depth of the CFD case (m). Used for the dispersion relation, depth type, wave length and energy flux. A warning is printed when it differs from the BEM depth of the HydroSphere (the models use the BEM depth)
    wave_energy_fraction float Energy fraction kept by the wave decomposition (frequency band around the peak), e.g. 0.999
    n_wave_components int | "all" Number of largest wave components used for the dynamic pressure of the CFD-side panel force f_fk_nl_x
    cases list[dict] List of cases to process (see cases)
    plot_options dict Controls which plots are generated (see plot_options)

    cases¶

    Each entry in cases:

    Field Type Required Description
    T float yes Wave period from the CFD folder name (s), written as a float (10.0, not 10)
    H float yes Wave height from the CFD folder name (m)
    damping int | null yes PTO damping coefficient (N·s/m). null for a wave-only case
    stiffness int | null yes PTO stiffness coefficient (N/m). Use negative for spring-like reactive control. null for a wave-only case
    tag string | null no Optional suffix appended to the CFD folder name and output label
    plot bool no Whether to include this case in plots. Default: true

    The case folder read in data/cfd/ is out_Case_<T>_<H>[_<damping>_<stiffness>][_<tag>], with T and H written without the dot (e.g. out_Case_65_20_120000_-430000_example, out_Case_66_20_emptybasin).

    Each case is assigned a label, built from the measured \(H_s\) and \(T_e\) and the case parameters. The label is used as the series label in plots and as the group name in run_validate and run_metric:

    Hs{Hs}p{dec}_Te{Te}p{dec}[_d{damping}_k{stiffness}][_{tag}]

    Example: Hs2p2_Te6p6_d120000_k-430000_example. The processed CSV files are named after the nominal H and T of the config instead (e.g. Hs2p0_Te6p5_d120000_k-430000_example_data.csv).

    plot_options¶

    Field Type Description
    sea_state bool Spectrum realization (one figure, one subplot per wave: FFT, filtered FFT, Welch and theoretical JONSWAP), elevation time series, measured vs recomposed elevation per case, and sea state grid
    power bool Absorbed power time series, power grid, and accumulated energy
    dynamics bool Displacement, velocity time series, and phase plot (x vs ẋ)
    hydro bool Hydrodynamic force breakdown: draft, linear forces, CFD forces, linear vs nonlinear comparisons
    3d bool 3D scatter of displacement, velocity, and wave elevation
    variable list of strings One time-series plot per named column from _data.csv, e.g. ["fe_lin", "x"]. A sub-list overlays its columns on one figure. [] for none

    power, dynamics, hydro and 3d need the body motion: they are skipped (warning) for wave-only cases.

    Outputs¶

    The output structure is described below.

    data/handled/<name>/
├── <name>.json                     ← copy of the config used
├── run.log
├── data/
│   ├── <case>_data.csv             ← full time series per case
│   ├── <case>_wave.csv             ← wave parameters and spectrum (Hs, Te, J, …)
│   ├── <case>_wave_recon.csv       ← wave components A, w, k, phi
│   └── <case>_wg_positions.csv     ← gauge positions (several gauges only)
└── plots/
    ├── spectrum.png / .pkl
    ├── <label>_eta_rec.png / .pkl
    ├── <label>_power.png / .pkl
    ├── <label>_dynamics.png / .pkl
    ├── <label>_hydro.png / .pkl
    └── <label>_<variable>.png / .pkl

    time series (data/_data.csv)¶

    Columns marked body exist only for a case with a body.

    Column Units Description
    t s Time
    eta m Wave elevation at the reference gauge (x = 0)
    eta_wg<i> m Wave elevation at gauge i (several gauges only)
    etadot m/s Wave elevation time derivative
    eta_rec m Recomposed wave elevation (sum of the components of _wave_recon.csv)
    x m Displacement (body)
    xdot m/s Velocity (body)
    xddot m/s² Acceleration (body)
    fhyd_cfd N Total fluid force from CFD (body)
    ftot N Total force on the body from CFD (ForceTotal_z_N_) (body)
    F_hyd N Total fluid force role column (= fhyd_cfd), same name as in the models (body)
    fd_pto, fs_pto, fpto N PTO damping, spring and total force (fpto = fd_pto + fs_pto) (body)
    Pd, Ps, Pabs W Damping, spring and absorbed power (Pabs = Pd + Ps) (body)
    Pabs_mean, Pd_mean, Ps_mean W Mean powers (scalar, repeated) (body)
    Eabs_accum, Ed_accum, Es_accum J Accumulated energies (body)
    CWRabs — Capture width ratio (body)
    fg N Gravity force on sphere (body)
    fi N Inertia force (body)
    Sw, Vs m², m³ Wetted surface and submerged volume (no η) (body)
    fb_nl, fhs_nl N Nonlinear buoyancy and hydrostatic force incl. gravity (no η) (body)
    Sw_eta, Vs_eta m², m³ Wetted surface and submerged volume (with η) (body)
    fb_nl_eta, fhs_nl_eta N Nonlinear buoyancy and hydrostatic force incl. gravity (with η) (body)
    fhs_lin, fb_lin N Linear hydrostatic force incl. gravity, and linear buoyancy (body)
    fe_lin N Linear excitation force (total IRF convolution) (body)
    f_fk_lin, fd_lin N Froude-Krylov and diffraction parts of fe_lin (body)
    fr_damp N Radiation damping force (state space) (body)
    fr_lin N Total radiation force (state space and added mass) (body)
    fhd_lin_comp N Linear hydrodynamic force (fe_lin + fr_lin) (body)
    fhyd_lin N Total linear fluid force (fhd_lin_comp + fb_lin) (body)
    fhd_lin_r, fhd_nl_r, fhd_nl_eta_r N Deduced hydrodynamic force incl. radiation: fhyd_cfd − fb_lin, − fb_nl, − fb_nl_eta (body)
    fhd_lin, fhd_nl, fhd_nl_eta N Deduced hydrodynamic force excl. radiation: same minus fr_lin (body)
    fhs_nl_eta_x N Panel static force, reference z = η, recomposed η(x, t) (body)
    fhs_nl_eta_z0_x N Panel static force, reference z = 0 (Giorgi), recomposed η(x, t) (body)
    f_fk_nl_x N Panel nonlinear Froude-Krylov force, recomposed η(x, t) (body)
    d m Active draft (body)

    wave parameters (data/_wave.csv)¶

    The spectrum rows are cut to the frequency band of the decomposition, so the rows of _wave.csv and _wave_recon.csv match.

    Column Units Description
    w rad/s Frequency axis
    S_fft m²·s/rad Raw FFT spectral density
    S_fft_filt m²·s/rad Smoothed FFT spectral density (5-point moving average)
    S_welch m²·s/rad Welch spectral density (interpolated onto the FFT grid)
    S_th m²·s/rad Theoretical JONSWAP spectrum (γ = 3.3) with the measured \(H_s\) and \(T_e\), peak at \(T_p = T_e / 0.903\)
    Te s Energy period (from S_fft_filt moments)
    Hs m Significant wave height (from S_fft_filt moments)
    J W/m Wave energy flux \(J = E\,c_g\) at the water depth
    eps — Wave steepness
    S_type, gamma — Theoretical spectrum type and peak enhancement factor
    water_depth m or "deep" Water depth of the case (input)
    depth_type — deep, intermediate or shallow, from \(h / L_0\) (thresholds 0.5 and 0.05)
    wave_length m Wave length at \(T_e\), with the formula of its depth type
    wave_energy_fraction — Energy fraction of the decomposition (input)
    n_wave_comp — Number of wave components in the band
    w_start, w_end rad/s Frequency band of the components
    eta_rec_nrmse_true — Fit of eta_rec against eta (NRMSE normalised by the RMS of eta)

    wave components (data/_wave_recon.csv)¶

    Column Units Description
    A m Component amplitude
    w rad/s Angular frequency
    k rad/m Wave number (dispersion relation at the case water depth)
    phi rad Phase, with \(\eta(x, t) = \sum A \cos(\omega t - k x + \varphi)\), absolute time
