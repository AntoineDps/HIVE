    run_handle_data¶

    Processes raw CFD time series into a standardised format ready for validation and identification.

    Run¶

    first run¶

    python -m script.run_handle_data --case <name>.json

    Config files ´.json´ live in inputs/handle_case/. The filename stem becomes the output folder name under data/handled/.

    rerun options¶

    When the output folder already exists, the script prompts:

    [1] erase and redo all     — reprocess + replot from scratch
[2] stop, do nothing
[3] load saved figures     — reopen existing .pkl plots interactively
[4] remake figures only    — reuse processed CSVs, regenerate plots

    Option [4] is useful when tuning plot parameters without reprocessing data.

    what it does¶

    1. Reads each CFD case folder from data/cfd/
    2. Instantiates a DataHandle object per case
    3. Calls processData() — computes radiation force, hydrostatic force, linear excitation force (fe_lin), and absorbed power
    4. Optionally resamples to a target dt
    5. Saves processed data and wave parameters to data/handled/<name>/data/
    6. Generates and saves plots to data/handled/<name>/plots/

    Input JSON config¶

    {
  "wave_type": "irr",
  "cut_time": [30, 0],
  "duration": null,
  "hydro_sphere_pkl": "r5",
  "dt": 0.05,
  "cases": [
  {
    "T": 6.5,
    "H": 2.0,
    "damping": 120000,
    "stiffness": -430000,
    "tag": "example",
    "plot": true
  },
  {
    "T": 6.5,
    "H": 3.0,
    "damping": 140000,
    "stiffness": -400000,
    "tag": "example",
    "plot": true
  }
],
  "plot_options": {
    "sea_state": true,
    "power": true,
    "dynamics": true,
    "hydro": true,
    "3d": true,
    "variable": ["fe_lin", "x"]
  }
}
    Field Type Required Description
    wave_type "irr" | "reg" yes Wave type used in the CFD simulation
    cut_time [float, float] yes Seconds to discard from [start, end] of the raw signal. Use 0 to keep to the edge
    duration float | null no Maximum duration (s) to retain after the start cut. null keeps all remaining data
    hydro_sphere_pkl string yes Stem of the BEM .pkl file in source/models/bem/. e.g. "r5" loads r5.pkl
    dt float | null no Target resampling timestep (s). null keeps the original CFD timestep
    cases list[dict] yes List of CFD cases to process (see cases)
    plot_options dict no Controls which plots are generated (see plot_options)

    cases¶

    Each entry in cases:

    Field Type Required Description
    T float yes Wave period from the CFD folder name (s)
    H float yes Wave height from the CFD folder name (m)
    damping int yes PTO damping coefficient (N·s/m)
    stiffness int yes PTO stiffness coefficient (N/m). Use negative for spring-like reactive control
    tag string | null no Optional suffix appended to the CFD folder name and output label
    plot bool no Whether to include this case in plots. Default: true

    Each CFD case is assigned a label derived from the CDF folder case name which contain parameters. An optional "tag" field in the case config appends a suffix. The label is used as the CSV filename stem and as the series label in plots:

    Hs{H}p{dec}_Te{T}p{dec}_d{damping}_k{stiffness}_{tag}

    Example: Hs2p0_Te8p0_d120000_k-280000_example

    plot_options¶

    Field Type Description
    sea_state bool Wave spectrum, elevation time series, and sea state grid
    power bool Absorbed power time series, power grid, and accumulated energy
    dynamics bool Displacement, velocity time series, and phase plot (x vs ẋ)
    hydro bool Hydrodynamic force breakdown: draft, linear forces, CFD forces, linear vs nonlinear comparisons
    3d bool 3D scatter of displacement, velocity, and wave elevation
    variable list of strings | false One time-series plot per named column from _data.csv. e.g. ["fe_lin", "x"]

    Outputs¶

    data/handled/<name>/
├── <name>.json               ← copy of the config used
├── run.log
├── data/
│   ├── <label>_data.csv      ← full time series per CFD case
│   └── <label>_wave.csv      ← scalar wave parameters (Hs, Te, J, …)
└── plots/
    ├── <label>_sea_state.png / .pkl
    ├── <label>_power.png / .pkl
    ├── <label>_dynamics.png / .pkl
    ├── <label>_hydro.png / .pkl
    └── <label>_<variable>.png / .pkl

    time-series (_data.csv)¶

    Column Units Description
    t s Time
    x m Displacement
    xdot m/s Velocity
    eta m Wave elevation
    fhyd_cfd N Total nonlinear fluid force from CFD
    fd_pto N PTO damping component
    fs_pto N PTO spring component
    fpto N Total PTO force (fd_pto + fs_pto)
    Pd W Damping power component
    Ps W Spring (reactive) power component
    Pabs W Instantaneous absorbed power (Pd + Ps)
    Pabs_mean W Mean absorbed power (scalar, repeated)
    Pd_mean W Mean damping power (scalar, repeated)
    Ps_mean W Mean spring power (scalar, repeated)
    Eabs_accum J Accumulated absorbed energy
    Ed_accum J Accumulated damping energy
    Es_accum J Accumulated spring energy
    CWRabs — Capture width ratio
    etadot m/s Wave elevation time derivative
    xddot m/s² Acceleration
    fg N Gravity force on sphere
    fi N Inertia force
    Sw m² Wetted surface area (no η)
    Vs m³ Submerged volume (no η)
    fhs_nl N Nonlinear hydrostatic force (no η)
    fb_nl N Nonlinear buoyancy including gravity (no η)
    Sw_eta m² Wetted surface area (with η)
    Vs_eta m³ Submerged volume (with η)
    fhs_nl_eta N Nonlinear hydrostatic force (with η)
    fb_nl_eta N Nonlinear buoyancy including gravity (with η)
    fb_lin N Linear buoyancy including gravity
    fhs_lin N Linear hydrostatic force
    fe_lin N Linear excitation force (IRF convolution)
    fr N Radiation force (state-space)
    fhd_lin_comp N Linear hydrodynamic composite (fe_lin + fr)
    fhyd_lin N Total linear fluid force (fhd_lin_comp + fhs_lin)
    fhd_lin N Deduced linear hydrodynamic force (fhyd_cfd − fb_lin)
    fhd_nl N Deduced nonlinear hydrodynamic force (fhyd_cfd − fb_nl)
    fhd_nl_eta N Deduced nonlinear hydrodynamic force with η (fhyd_cfd − fb_nl_eta)
    fhd_lin_r N Deduced linear hydrodynamic excl. radiation (fhyd_cfd − fb_lin − fr)
    fhd_nl_r N Deduced nonlinear hydrodynamic excl. radiation (fhyd_cfd − fb_nl − fr)
    fhd_nl_eta_r N Deduced nonlinear hydrodynamic with η excl. radiation (fhyd_cfd − fb_nl_eta − fr)
    d m Active draft

    wave parameters (_wave.csv)¶

    Column Units Description
    f or w Hz or rad/s Frequency axis (depends on freq setting)
    S_fft m²/Hz or m²·s Raw FFT spectral density
    S_fft_filt m²/Hz or m²·s Smoothed FFT spectral density (5-point moving average)
    S_welch m²/Hz or m²·s Welch spectral density (interpolated onto FFT grid)
    S_th m²/Hz or m²·s Theoretical JONSWAP spectrum
    Te s Energy period (from S_fft_filt moments)
    Hs m Significant wave height (from S_fft_filt moments)
    J W/m Wave energy flux
    eps — Wave steepness
    S_type — Spectrum type label (e.g. "JONSWAP")
    gamma — JONSWAP peak enhancement factor
