    run_validate¶

    Simulates one or more models against CFD reference data and computes comparison metrics. Accepts lists for all major fields and runs every combination of models, wave sources, solvers, and simulation modes in a single execution.

    Run¶

    first run¶

    python -m script.run_validate --case <name>.json

    Config files <name>.json live in inputs/validate_case/. The filename stem becomes the output folder name under out/validated_case/.

    rerun options¶

    When the output folder already exists, the script prompts:

    [1] erase and redo
[2] stop, do nothing
[3] load saved figures     — reopen existing .pkl plots interactively
[4] save with date suffix  — run and save under <name>_YYYYMMDD (keeps existing folder)

    what it does¶

    1. Loads each model definition from source/models/<name>/model.json
    2. Loads wave data from each wave_sources entry
    3. For every combination of (model × wave source × solver × eta input × simulation mode): runs a forward simulation
    4. Clips each simulated trajectory to the valid window (t_warmup, t_causal) computed from the model
    5. Computes comparison metrics against the CFD reference
    6. Saves result.json, simulation CSVs and plots to out/validated_case/<name>/

    Input JSON config¶

    Full example¶

    {
  "models": [
    {"name": "linear"},
    {"name": "linear_viscous"}
  ],
  "wave_sources": [
    {"type": "cfd_case", "case_name": "example_cases"}
  ],
  "solvers": [
    {"method": "rk4", "dt": 0.05, "interpolation": {}},
    {"method": "rk2", "dt": 0.05, "interpolation": {"fe": false}}
  ],
  "eta_inputs": [
    {"type": "true"}
  ],
  "simulation": [
    {"type": "closed_loop"}
  ],
  "plot_options": {
    "states": true,
    "forces": false
  }
}

    Top-level fields¶

    Field Type Options / values Description
    models list[dict] see models fields Models to validate. Multiple entries run all models in one execution
    wave_sources list[dict] see wave_sources entry fields Wave data sources. Multiple entries run each source against all models
    solvers list[dict] see solvers fields Solver configurations. Multiple entries run each solver configuration against all combinations
    eta_inputs list[dict] see eta_inputs fields Wave elevation input type for the simulation
    simulation list[dict] see simulation fields Simulation mode
    plot_options dict see plot_options fields Controls which plots are generated

    models fields¶

    Each entry in models:

    Field Type Options / values Description
    name string folder name under source/models/ — currently: "linear" · "linear_viscous" Model to simulate. Must contain model.json. See Base model reference for the model.json structure

    wave_sources entry fields¶

    Each dict in wave_sources must have a "type" key:

    "type": "cfd_case" — load from a handled CFD folder:

    Field Type Options / values Description
    type string "cfd_case" Source type selector
    case_name string stem of a folder under data/handled/ Handled case folder to load

    solvers fields¶

    Each entry in solvers:

    Field Type Default Options / values Description
    method string "rk4" "euler" · "rk2" · "rk4" (case-insensitive) ODE integration scheme
    dt float — any positive float (s) Fixed timestep
    interpolation dict {} keys: "fe", "fk", "eta_hs" — values: true / false Per-force-term interpolation flags. Empty dict enables interpolation for all terms

    interpolation flags¶

    The precomputed force signals (\(f_e^{lin}\), nonlinear FK force, wave elevation) are evaluated on the handled data grid. At ODE sub-stages, evaluations may fall between grid points. Each flag controls whether that term is re-evaluated at every sub-stage or frozen to the step-start value (zero-order hold).

    Key Force term Effect when true
    "fe" Linear excitation force \(f_e^{lin}\) Re-evaluated at each RK sub-stage
    "fk" Nonlinear Froude–Krylov force Re-evaluated at each RK sub-stage
    "eta_hs" Wave elevation for nonlinear hydrostatic Re-evaluated at each RK sub-stage

    Setting a flag to false freezes that term within each timestep (ZOH), which is cheaper but reduces effective accuracy for that term. An empty dict {} enables interpolation for all terms and is recommended for rk4 and rk2.

    "interpolation": {}                          // all terms interpolated (recommended)
"interpolation": {"fe": false}               // freeze excitation, interpolate rest
"interpolation": {"fe": false, "fk": false}  // freeze both, interpolate eta_hs only

    eta_inputs fields¶

    Each entry in eta_inputs:

    Field Type Options / values Description
    type string "true" Wave elevation source. "true" uses the measured CFD wave elevation \(\eta(t)\)

    simulation fields¶

    Each entry in simulation:

    Field Type Options / values Description
    type string "closed_loop" Simulation mode. "closed_loop" includes PTO feedback with the damping and stiffness from the wave case

    plot_options fields¶

    Field Type Default Options / values Description
    states bool true true / false Time series of \(x\), \(\dot{x}\), \(\eta\), \(f_{pto}\), \(P_{abs}\)
    forces bool false true / false Time series of individual force terms

    Multiple entries¶

    Field Accepts list? Effect
    models yes one simulation pass per model
    wave_sources yes each source run against all models and solvers
    solvers yes each solver configuration run against all combinations
    eta_inputs yes each input type run against all combinations
    simulation yes each simulation mode run against all combinations

    All combinations are run in a single execution. result.json stores metrics keyed by model name and case label, covering every combination.

    Metrics¶

    Metrics are computed for each simulated trajectory against the CFD reference:

    Name Description
    "rmse_x" RMSE of displacement \(x\) [m]
    "rmse_xdot" RMSE of velocity \(\dot{x}\) [m/s]
    "nrmse_x" Normalised RMSE of \(x\)
    "nrmse_xdot" Normalised RMSE of \(\dot{x}\)
    "mean_P_abs" Mean absorbed power \(P_{abs}\) [W]
    "rmse_P_abs" RMSE of absorbed power [W]

    Outputs¶

    out/validated_case/<name>/
├── <name>.json               ← copy of the config used
├── run.log
├── result.json               ← metric summary for all models and sea states
├── data/
│   └── <label>_simrun.csv    ← simulated time series per case per model
└── plots/
    ├── scatter_<metric>.png / .pkl
    └── timeseries_<label>.png / .pkl

    result.json structure¶

    {
  "t_warmup": 15.0,
  "t_causal": 3.2,
  "models": {
    "linear": {
      "T8_H2": {"nrmse_x": 0.12, "mean_P_abs": 430.5},
      "T10_H3": {"nrmse_x": 0.09, "mean_P_abs": 610.2}
    },
    "linear_viscous": {
      "T8_H2": {"nrmse_x": 0.06, "mean_P_abs": 435.1}
    }
  }
}
