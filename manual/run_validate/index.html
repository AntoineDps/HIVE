    run_validate¶

    Simulates one or more models against CFD reference data and computes comparison metrics. Accepts lists for all major fields and runs every combination of models, wave sources, solvers, and simulation modes in a single execution.

    Run¶

    first run¶

    python -m script.run_validate --case <name>.json

    Config files <name>.json live in inputs/validate_case/. The filename stem becomes the output folder name under out/validated_case/.

    rerun options¶

    When the output folder already exists, the script prompts:

    [1] erase and redo
[2] stop, do nothing
[3] load saved figures     — reopen existing .pkl plots interactively
[4] save with date suffix  — run and save under <name>_YYYYMMDD (keeps existing folder)

    what it does¶

    1. Loads each model definition from source/models/<name>/model.json
    2. Loads wave data from each wave_sources entry
    3. For every combination of (model × wave source × solver × eta input × simulation mode): runs a forward simulation
    4. Clips each simulated trajectory to the valid window (t_warmup, t_causal) computed from the model
    5. Computes comparison metrics against the CFD reference
    6. Saves result.json, simulation CSVs and plots to out/validated_case/<name>/

    Input JSON config¶

    Full example¶

    {
  "models": [
    {"name": "linear"},
    {"name": "linear_viscous"}
  ],
  "wave_sources": [
    {"type": "cfd_case", "case_name": "example_cases"}
  ],
  "solvers": [
    {"method": "rk4", "dt": 0.05, "interpolation": {}},
    {"method": "rk2", "dt": 0.05, "interpolation": {"fe": false}}
  ],
  "eta_inputs": [
    {"type": "true"}
  ],
  "simulation": [
    {"type": "closed_loop"}
  ],
  "plot_options": {
    "states": true,
    "forces": false
  }
}

    Config fields¶

    Field Type Options / values Description
    models list[dict] name: folder under source/models/ Models to validate. Each entry must contain model.json
    wave_sources list[dict] type: "cfd_case" · case_name: stem under data/handled/ Wave data sources
    solvers list[dict] method: "euler" · "rk2" · "rk4" · dt: float (s) · interpolation: see below Solver configurations
    eta_inputs list[dict] type: "true" (measured CFD elevation \(\eta(t)\)) Wave elevation input
    simulation list[dict] type: "closed_loop" (PTO feedback included) Simulation mode
    plot_options dict states: bool · forces: bool Controls which plots are generated

    solvers.interpolation¶

    Per-force-term flags — true re-evaluates at each RK sub-stage, false freezes to step-start (ZOH):

    Key Force term
    "fe" Linear excitation force \(f_e^{lin}\)
    "fk" Nonlinear Froude–Krylov force
    "eta_hs" Wave elevation for nonlinear hydrostatic

    Empty dict {} enables all terms (recommended for rk4 / rk2).

    plot_options fields¶

    Field Type Default Options / values Description
    states bool true true / false Time series of \(x\), \(\dot{x}\), \(\eta\), \(f_{pto}\), \(P_{abs}\)
    forces bool false true / false Time series of individual force terms

    Multiple entries¶

    Field Accepts list? Effect
    models yes one simulation pass per model
    wave_sources yes each source run against all models and solvers
    solvers yes each solver configuration run against all combinations
    eta_inputs yes each input type run against all combinations
    simulation yes each simulation mode run against all combinations

    All combinations are run in a single execution. result.json stores metrics keyed by model name and case label, covering every combination.

    Metrics¶

    Metrics are computed for each simulated trajectory against the CFD reference:

    Name Description
    "rmse_x" RMSE of displacement \(x\) [m]
    "rmse_xdot" RMSE of velocity \(\dot{x}\) [m/s]
    "nrmse_x" Normalised RMSE of \(x\)
    "nrmse_xdot" Normalised RMSE of \(\dot{x}\)
    "mean_P_abs" Mean absorbed power \(P_{abs}\) [W]
    "rmse_P_abs" RMSE of absorbed power [W]

    Outputs¶

    out/validated_case/<name>/
├── <name>.json               ← copy of the config used
├── run.log
├── result.json               ← metric summary for all models and sea states
├── data/
│   └── <label>_simrun.csv    ← simulated time series per case per model
└── plots/
    ├── scatter_<metric>.png / .pkl
    └── timeseries_<label>.png / .pkl

    JSON (result.json)¶

    {
  "t_warmup": 15.0,
  "t_causal": 3.2,
  "models": {
    "linear": {
      "T8_H2": {"nrmse_x": 0.12, "mean_P_abs": 430.5},
      "T10_H3": {"nrmse_x": 0.09, "mean_P_abs": 610.2}
    },
    "linear_viscous": {
      "T8_H2": {"nrmse_x": 0.06, "mean_P_abs": 435.1}
    }
  }
}
