    System Identification¶

    HIVE supports three identification schemes, each suited to a different modelling goal. This page covers the theory behind each one.

    Viscous drag identification¶

    Scheme key: viscous_drag

    The quadratic drag coefficient \(c_v\) is found by minimising a simulation error over a 1D grid:

    \[ c_v^* = \arg\min_{c_v \in [c_{v,\min},\, c_{v,\max}]} \mathcal{J}(c_v) \]

    where \(\mathcal{J}\) is a user-chosen objective (default: nrmse_x). The scheme:

    1. Builds a uniformly spaced grid of n_points values of \(c_v\)
    2. Runs a full simulation for each value using the base model + drag
    3. Evaluates the objective against the CFD reference
    4. Saves the grid and the best value

    This is a brute-force sweep — simple but robust for a one-dimensional search.

    PI gain identification¶

    Scheme key: pi_gain

    Identifies proportional and integral gains \((K_p, K_i)\) of a PI controller minimising a 2D objective grid:

    \[ f_{pto}(t) = K_p\,e(t) + K_i\int e(t)\,dt \]

    The scheme performs a 2D sweep over the Cartesian product of Kp_range and Ki_range, each with n_points points, and returns the \((K_p^*, K_i^*)\) pair with the best objective value.

    Linear system identification (linear_si)¶

    Scheme key: linear_si

    Identifies two linear state-space models from broadband signal data (not CFD cases):

    Model Input Output
    eta2f Wave elevation \(\eta\) Linear excitation force \(f_e^{lin}\)
    f2v \([f_e^{lin},\, f_{pto}]\) Velocity \(\dot{x}\)

    Both models are identified from signals generated by run_signals.

    Empirical Transfer Function Estimate (ETFE)¶

    Before fitting a parametric model, a non-parametric frequency response is estimated using the ETFE:

    \[ \hat{G}(\omega_k) = \frac{\hat{Y}(\omega_k)}{\hat{U}(\omega_k)} \]

    where \(\hat{U}\) and \(\hat{Y}\) are the DFT of the input and output at frequency \(\omega_k\). Because the multi-sine signal is exactly periodic, the DFT is evaluated only at the excited harmonics, and the ETFE is unbiased for those frequencies.

    A rectangular smoothing window of length smooth_window is applied to reduce variance at the cost of frequency resolution.

    Vector Fitting (VF) — eta2f¶

    Vector Fitting (Gustavsen & Semlyen 1999) fits a rational transfer function to the ETFE:

    \[ G(s) = \sum_{k=1}^{n} \frac{r_k}{s - p_k} + d + s\,h \]

    HIVE sweeps over a list of pole orders (order_list) and a causality delay grid (tau_min, tau_max, n_tau). The delay accounts for the non-causal nature of the excitation force:

    \[ \tilde{G}(s) = G(s)\,e^{-s\tau} \]

    For each \((n, \tau)\) pair the fitting error is computed, and the combination with the lowest error over the target frequency range [w_start, w_end] is selected. The best model is converted to a state-space realisation \((A, B, C, D)\).

    N4SID — f2v¶

    The force-to-velocity transfer function is identified using the subspace method N4SID (Van Overschee & De Moor 1994):

    \[ \begin{aligned} \dot{\mathbf{x}} &= A\mathbf{x} + B\mathbf{u} \\ y &= C\mathbf{x} + D\mathbf{u} \end{aligned} \qquad \mathbf{u} = [f_e^{lin},\, f_{pto}]^\top,\quad y = \dot{x} \]

    N4SID works directly in the time domain using block-Hankel matrices. The num_block_rows parameter controls the size of the Hankel matrix, which sets the upper bound on the identifiable system order.

    Full identification pipeline¶

    run_signals  →  CFD/WEC experiment  →  CSV signal files
                                              │
                              ┌───────────────┼────────────────┐
                              ▼               ▼                ▼
                       ETFE (eta→fe_lin)  ETFE (fe,fpto→xdot)
                              │               │
                         VF + causality    N4SID
                         delay sweep          │
                              │               │
                         eta2f SS model   f2v SS model
                              └───────────────┘
                                      │
                               model.json  (saved to models/<name>/)

    Causality constraint¶

    The excitation force is non-causal: the transfer function \(F_e(\omega)/\hat{\eta}(\omega)\) has energy at negative times in its IRF. A causal model cannot reproduce this exactly. By sweeping a delay \(\tau\) (which shifts the IRF forward in time), HIVE finds the minimum delay that makes the model approximately causal while preserving accuracy. The selected \(\tau\) becomes t_causal in the model definition and is used to clip simulation results in run_validate.
